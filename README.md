Description:
This project is a console-based Student Management System developed in C#. It allows users to manage student records efficiently through a menu-driven interface. The system demonstrates core Object-Oriented Programming (OOP) principles and practical data handling techniques.

Features:
Add new students with ID, name, and grades
Remove students from the system
Search for students by ID
Display all students with calculated average grades
Input validation and error handling

Concepts Demonstrated
Classes and Objects
Encapsulation
Static members
Collections (List<T>)
Exception Handling
Regular Expressions (Regex validation)

How to Run
Open the project in Visual Studio
Build the solution
Run the program
Follow the menu options
